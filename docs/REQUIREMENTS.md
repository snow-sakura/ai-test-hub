# AI 测试中枢 — 需求规格说明书

> 版本：v1.1 ｜ 更新日期：2026-10-18

## 1. 产品定位

AI-Test-Hub 是一站式 AI 测试平台：以「需求 → AI 生成测试用例 → AI 评审 → 改进 → 用例库/评审/执行/报告」为主线，辅以 AI 聊天室、API 测试、知识库、系统管理等模块。

## 2. 本次迭代需求（生成序列与可靠性）

### R1 生成序列（批量任务）
- **用户故事**：作为测试负责人，我希望一次粘贴多条测试需求（每行一条），系统自动创建一组生成任务并按序执行，以便批量覆盖多个功能点。
- **规则**：
  - 每条需求生成一个独立任务，归属同一批次 `batch_id`；
  - 批次内任务共享模型、提示词、评审开关等配置；
  - 序列看板实时展示每个任务的状态（排队/运行/完成/失败）、进度与结果入口。

### R2 免费/付费模型差异化调度
- **用户故事**：作为平台使用者，我希望免费模型的任务自动排队串行执行（避免触发限流），付费模型的任务并行执行（缩短批量耗时）。
- **规则**：
  - 模型配置新增「计费类型」：免费 / 付费（默认免费）；
  - 免费模型：全局并发 = 1，任务依次执行，界面显示排队位次；
  - 付费模型：全局并发 = `PAID_MODEL_CONCURRENCY`（默认 4，可配置）；
  - 同一批次统一按编写模型的计费类型决定 `serial / parallel` 执行模式并在界面提示。

### R3 生成结果可靠性
- 任一阶段失败不得丢失已完成阶段的成果（阶段级持久化）；
- 评审/改进失败降级为告警，不推翻生成结果；
- 解析不到用例时明确告警并展示模型原文，禁止"空结果假成功"；
- SSE 断线可重连回放，页面刷新不丢进度；
- 服务重启后遗留任务自动置为失败并给出原因，可一键重新生成；
- 「继续生成」真正从断点阶段续跑，复用已有产物。

### R4 前端展示优化
- 阶段循环序列时间线：排队 → 需求分析 → 用例编写 → AI 评审 → 改进完善 → 完成；
- 模型下拉/配置页可见计费类型与执行模式提示；
- 结果区空态兜底（原始输出可查）。

### R5 文档与演示
- README 全流程文档（主/副标题 + 文字 + 截图）；
- GitHub Pages 纯静态 Demo（数据为演示样例）；
- 需求/技术/操作说明文档随仓库发布。

## 3. 非功能需求

- 兼容性：既有任务列表、详情、报告、保存到用例库等接口保持向后兼容；
- 安全：API Key 仅存数据库/环境变量，仓库与 Demo 不含任何真实密钥；
- 质量门槛：`vue-tsc` 零错误、`eslint` 通过、浏览器控制台无报错。
